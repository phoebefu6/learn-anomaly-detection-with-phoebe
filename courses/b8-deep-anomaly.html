Part 0

The one idea: reconstruction error

Almost every deep anomaly detector rests on a single move. Train a model to compress and then rebuild normal data. Force the information through a narrow bottleneck and the model can only learn to reproduce the patterns it saw most - the normal ones. Feed it a normal point and it rebuilds it well; feed it an anomaly and it rebuilds it badly, because it never learned that shape. The size of that rebuild miss - the reconstruction error - is the anomaly score. That is the whole thesis, and it survives from linear PCA all the way to deep autoencoders.

Part 1 · the autoencoder

Compress, rebuild, measure the miss 6 min live

An autoencoder is two halves. The encoder squeezes an input into a small latent vector; the decoder expands that vector back toward the original. Train it only on normal data with a reconstruction loss, and the bottleneck forces it to keep just the structure that normal data shares. Anomalies do not share that structure, so they come back distorted - and that distortion is the score.

LiveThe deep family, in one breath each3 min▶
  • Autoencoder - the base case above. Reconstruction error is the score.
  • LSTM-autoencoder - the same idea for sequences. It reconstructs a whole window of a time series; a window it rebuilds poorly is an anomalous stretch. This is the natural deep cousin of the forecast-residual detector in b7.
  • Deep one-class / VAE - a one-line nod: Deep SVDD learns a tight boundary around normal in a learned space, and a variational autoencoder scores by reconstruction probability. Same spirit, different machinery.
Real world · honest read

Deep is not a free upgrade. Autoencoders need a lot of clean normal data, careful architecture and threshold tuning, and compute - and on a single low-dimensional series they frequently do not beat an isolation forest (b5) or a good seasonal detector (b3, b7). Reach for deep methods when the data is genuinely high-dimensional or complex - images, logs, multivariate sensor streams - where the structure a shallow model cannot capture is exactly where anomalies hide.

Part 2 · error becomes the score

Reconstruction error over time 5 min live

Once trained, the detector is simple: push every point (or window) through, measure how far the rebuild lands from the original, and threshold that error. Plot the error over time and the anomalies announce themselves - normal points hug a low baseline, anomalies spike above the line. The threshold is the usual precision/recall decision, and setting it on a clean stretch of normal errors is the whole game.

Self-studyThe three ways this bites you2 min read▶

Reconstruction-error detectors fail in predictable ways - know them before you ship one:

  • Contaminated training - if anomalies leak into the "normal" training set, the model learns to rebuild them too, and stops flagging them. Curate the normal sample.
  • Over-capacity - a bottleneck that is too wide (or a model too powerful) learns to rebuild everything, anomalies included, and the error signal collapses. The squeeze is the point.
  • Threshold drift - as the normal regime shifts, yesterday's error threshold turns into today's false-alarm generator. Re-estimate it on fresh normal data.
Demo 1 of 2 · runnable

PCA reconstruction error ★ 12 min · everyone builds

The concept made concrete, and actually runnable. PCA is a linear autoencoder: project each window onto a few components, then project back. Normal windows rebuild well; the anomalous ones rebuild badly, and the squared rebuild error is the anomaly score - no deep-learning library required.

Rebuild the labeled Lumen series (from b1) so the notebook runs standalone.

Turn the series into a feature matrix of overlapping 7-day windows.

Fit PCA, reconstruct, and take the per-window squared error as the score.

Threshold robustly and score precision, recall, and F1 against truth.

★ Run it now (Python) - PCA as a linear autoencoderimport pandas as pd, numpy as np from numpy.lib.stride_tricks import sliding_window_view from sklearn.decomposition import PCA # --- rebuild the labeled Lumen series (from b1) --- idx = pd.date_range("2026-01-01", periods=90, freq="D") season = np.array([30,42,48,40,22,-95,-110]) i = np.arange(90) y = 900 + 1.2*i + season[i % 7] + 10*np.sin(i*1.7) + 7*np.cos(i*0.6) truth = [20, 45, 63, 70, 71, 72] y[20] += 430; y[45] -= 380 y[63] = y[63] - season[63 % 7] + season[6] - 40 y[[70,71,72]] += [175,190,170] s = pd.Series(np.round(y), index=idx, name="sessions") # --- windows -> PCA reconstruction error (a linear autoencoder) --- v = ((s - s.mean()) / s.std()).to_numpy() w = 7 X = sliding_window_view(v, w) # (84, 7) overlapping windows pca = PCA(n_components=2).fit(X) # bottleneck = 2 components Xr = pca.inverse_transform(pca.transform(X)) # encode then decode err = ((X - Xr) ** 2).mean(axis=1) # reconstruction error per window # map each window's error to its last day, then threshold robustly score = np.full(len(s), np.nan); score[w-1:] = err m = np.nanmedian(err); iqr = np.nanpercentile(err,75) - np.nanpercentile(err,25) flags = set(np.where(score > m + 3*iqr)[0]) tp = len(flags & set(truth)); fp = len(flags - set(truth)); fn = len(set(truth) - flags) prec = tp/(tp+fp) if tp+fp else 0; rec = tp/(tp+fn) if tp+fn else 0 f1 = 2*prec*rec/(prec+rec) if prec+rec else 0 print(f"PCA-recon caught {tp}/{len(truth)} precision {prec:.2f} recall {rec:.2f} F1 {f1:.2f}") # a linear autoencoder; a deep one replaces PCA with a nonlinear encoder/decoder
This is the honest bridge to deep PCA reconstruction error is the deep idea stripped to linear algebra - runnable in seconds, no GPU. A real autoencoder swaps the linear projection for a nonlinear network, which helps only when the normal structure is genuinely nonlinear. If PCA-recon already ties your isolation forest here, that is your signal that this series does not need deep at all.

Check yourself

Three questions before you go 🎯 ◐ 90 seconds

1 · In a reconstruction-based detector, what is the anomaly score?

The model learns to rebuild normal data through a bottleneck. Anomalies were never learned, so they come back distorted; that distortion (the reconstruction error) is the score.

2 · When are deep methods most worth the extra cost?

On one low-dimensional series, an isolation forest or seasonal detector often matches or beats an autoencoder. Deep pays off where the structure is too complex for a shallow model.

3 · Why does PCA reconstruction error illustrate the deep idea?

Projecting onto a few components then back is exactly encode-then-decode. A deep autoencoder just replaces that linear projection with a nonlinear network.
